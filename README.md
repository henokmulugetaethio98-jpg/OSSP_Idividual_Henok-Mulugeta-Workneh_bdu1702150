# Operating System Project: BeOS Installation and Virtualization

## Overview
This project involves installing the legacy **BeOS** in a **VMware Workstation** environment. It explores virtualization, filesystem design, and the installation process of outdated operating systems. The project provides a hands-on experience with configuring virtual machines and troubleshooting installation issues.

## Key Objectives:
- **Install BeOS in VMware Workstation**: Learn how to configure virtual hardware and troubleshoot installation steps.
- **Explore BeFS**: Understand BeOS's unique filesystem (BeFS) and compare it with modern filesystems.
- **Virtualization Concepts**: Gain practical knowledge in virtual machine configuration, resource allocation, and system management.
